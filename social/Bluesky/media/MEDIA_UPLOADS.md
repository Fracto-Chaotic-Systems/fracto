# Bluesky media uploads

This ledger records images and other media uploaded for the Fracto Bluesky
account. Entries are listed newest first, with one entry per media asset. Each
entry should use the thumbnail as the visual reference and link that thumbnail
to the full-size asset.

## Entry format

### YYYY-MM-DD — short description

[![Thumbnail](THUMBNAIL_URL)](FULL_SIZE_URL)

- **Uploaded:** YYYY-MM-DD HH:MM UTC
- **Media key:** `POST_CID/BLOB_CID`
- **Post URI:** `at://DID/app.bsky.feed.post/RECORD_KEY`
- **Post CID:** `POST_CID`
- **Blob CID:** `BLOB_CID`
- **Media type:** image, gallery image, video, or other supported type.
- **Full-size media:** [open original](FULL_SIZE_URL)
- **Source post:** [view post](POST_URL)
- **Alt text:** description for accessibility and editorial search.
- **Notes:** optional campaign, crop, or reuse notes.

`Media key` is the stable deduplication key. The post CID identifies the
Bluesky record and the blob CID identifies the uploaded media object. Keep
these values unchanged even if the descriptive title, notes, or links are
updated later.
